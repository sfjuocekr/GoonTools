# GoonTools
The official Goon Squad addon

# Features
- Makes a screenshot when you level up!
- Automagically accepts party/raid invites by guild members.
- Invites a guild member based on keywords (inv and invite).
- Congratulate a guild member when it, they, she or he reaches the next level!

# Slash commands
- /gt	Open GoonTools Configuration!
- /ffa	Set loot to Free For All.
- /gl	Set loot to Group Loot.
- /pl	Leave the current party.
